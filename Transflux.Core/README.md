# Transflux.Core

Dependency-free .NET 10 conversion foundation referenced by CLI, desktop and tests. New XML and PDF extraction converters implement IFileConverter; each invocation writes one complete output to the supplied temporary path. Instances must support concurrent calls when Workers exceeds one. The runner preserves sources, captures timestamps before reading, publishes completed outputs by same-directory move, and exposes per-file results and progress. Cancellation throws and leaves previously committed results intact; progress callbacks may arrive concurrently. Folder planning preserves relative paths, rejects duplicate destinations and nested output folders, and excludes discovered reparse points. Use trusted source and output directories; this is not a filesystem sandbox. Timestamp support varies by filesystem. Existing image and Ghostscript conversion pipelines remain unchanged until adapters are implemented; their multi-output and in-place semantics are not represented by this single-output contract. Multi-table exports and persistent recovery are later milestones.

Run regression tests using `dotnet test ReaKiller.Tests/ReaKiller.Tests.csproj -c Release`.
